# Credit-Card-Transaction-Analysis-
A comprehensive Python and Power BI analytics project that analyzes 1.29M+ credit card transactions to uncover geographic patterns, transaction behaviors, customer segments, and fraudulent activity.

# Data Source - Kaggle
The data used was derived from Credit_Card_Transaction.csv

# Feature Engineering - Python
I utilized Python (Google Colab) to extract and analyze key features from large datasets, focusing on geospatial patterns, customer behavioral trends, and fraud detection.

As part of the analysis, I conducted geospatial distance modeling by leveraging customer latitude and longitude coordinates to identify location-based transaction patterns, anomalies, and potential fraudulent activities.

Additionally, I performed business category classification and fraud analytics, evaluating fraud trends across different business segments. This analysis incorporated factors such as business category, transaction value, transaction location (state), and time of transaction to uncover high-risk patterns, assess transaction behavior, and identify potential fraud indicators.

The insights derived from these analyses supported data-driven decision-making, enhanced fraud monitoring capabilities, and improved the understanding of customer and business transaction behavior.
